# Practice pitch: suggested 3-minute MVP demonstration

## Flow (180 seconds, rehearsed estimate)

**0:00–0:45 — New student**
Open New Student → Learning Request. Show Subject, Grade, Goal, optional note, **three quick preferences**, Schedule and Budget. Click Find Top 3. The loading animation precedes a deterministic ranking (not an AI model call).

**0:45–1:20 — Tutor verification and course activation**
Open New Tutor → three-step profile (pre-filled example) → Verification. Switch to Admin, approve initial scope. Switch back: **Teaching subjects** shows Mathematics/M.4 approved. Click Publish course (no more approval).

**1:20–1:45 — New subject without re-verifying existing courses**
Request Physics/M.4. Point out Physics is Pending but Math course is still active. Admin approves Physics alone; no repeat identity screening.

**1:45–2:20 — Existing tutor / BYOS**
For smoother presentation, use pre-prepared Returning Tutor screens: show a group with two BYOS students, open seats and an example learning plan. Mention marketplace commission as a proposal to test, not an established paid product.

**2:20–3:00 — Parent progress and LINE**
With Returning Tutor scenario, save a sample Session Note; switch Demo view to Parent, open Progress and the LINE Flex-style preview. Clearly state no actual LINE messages are sent.

**Do not try to type every field live:** Instead demo one representative input change and use screenshots/prepared pages for the other steps. This 3-minute sequence is a practice plan and may need further shortening during rehearsal.
